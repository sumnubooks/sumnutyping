Punctuation

Sixth lesson. Marks such as period, comma, exclamation, and question mark.

Last updated: September 23, 2026

The list is short words with a mark attached: hello. world! yes, ok? well, and similar fragments. You are practicing the mark, not a new vocabulary. On the diagram, comma is a right-middle reach below K, and period is a right-ring reach below L. Question mark and exclamation mark need shift. Hold shift with the pinky on the other hand from the finger that types the mark. Using the same hand for both is the usual tangle.

Do not add speed until the mark lands on purpose. Braces and arrows belong to Code mode later. This lesson stays with ordinary sentence marks. It is the last drill in the sequence, and finishing it is not a certificate. Keep a 60-second test in the week so the marks show up in a measurement.
