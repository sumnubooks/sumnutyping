Guides

Reading that sits next to the tools: how a mode works, how a lesson is built, and what a score is for.

Last updated: September 23, 2026

These pages are the reading layer around SumnuTyping. The tests, lessons, and games stay on the home site and still run the same way. The guides explain the choices those screens already make, in language you can open without clicking through a hidden view. Each guide is about one part of the product. They are not a pile of interchangeable “type faster” posts.

If you are about to practice, read the practice guide once, then use the tool. If you are new to touch typing, start at the learn hub and open the lesson that matches the row you are on. The three articles that used to live only on the home page now have their own addresses too, so a link to “what is WPM” does not depend on scrolling the front page.

Lesson notes

Each lesson has a short introduction of its own. The drill still lives on the Learn screen. The note tells you which fingers, which keys, and which mistake to watch before you press Start.
